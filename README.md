# Katun Studio

โปรแกรมทำวิดีโอการ์ตูน 2D ด้วย AI: เขียนบท → สร้างเสียงพูด (หรืออัดเอง) → ตัวละครขยับปากตามเสียง → ซับไตเติล + เพลงประกอบ → MP4

ใช้ได้ 3 ทาง:
1. **หน้าจอโปรแกรม (Katun Studio):** เปิดจากไอคอนบนเดสก์ท็อป
2. **ให้ AI ทำให้ผ่าน MCP:** Claude Desktop / Claude Code สั่งเขียนบท ลงเสียง ดูภาพ และเรนเดอร์ได้เอง
3. **คำสั่งใน Terminal:** `katun ...`

## ติดตั้ง (Windows)

ดับเบิลคลิก **`install.cmd`** แล้วตอบคำถาม ตัวติดตั้งจะ:

- ตรวจ Node.js 20+ (ถ้าไม่มีจะเสนอติดตั้งด้วย winget)
- ติดตั้งไลบรารีและตัวเรนเดอร์วิดีโอ (Chrome Headless ของ Remotion)
- สร้างไอคอน **Katun Studio** บนเดสก์ท็อปและใน Start Menu
- ลงทะเบียนคำสั่ง `katun` ให้ใช้ใน Terminal ได้
- ถามว่าจะดาวน์โหลด Rhubarb (ปากขยับแม่นยำ) และเชื่อมกับ Claude Desktop หรือไม่

ถ้าต้องการติดตั้งแบบไม่ถาม: `powershell -ExecutionPolicy Bypass -File install.ps1 -Unattended -WithRhubarb -ConnectClaude`

ถอนการติดตั้ง: `powershell -ExecutionPolicy Bypass -File uninstall.ps1` (โปรเจกต์ใน `projects\` จะยังอยู่)

## ใช้หน้าจอโปรแกรม

เปิด **Katun Studio** จากไอคอนบนเดสก์ท็อป / Start Menu หรือพิมพ์ `katun` โปรแกรมจะขึ้นเป็นหน้าต่างของตัวเอง ไม่มีแถบเบราว์เซอร์ และไม่มีหน้าต่างดำ ปิดหน้าต่าง = ปิดโปรแกรม ทุกอย่างทำงานบนเครื่องคุณเท่านั้น
- **ตัวหน้าต่าง:** ใช้ Microsoft Edge (มีในทุกเครื่อง Windows) ในโหมดแอป
- **อยากเปิดเป็นแท็บในเบราว์เซอร์แทน:** ใช้ `katun --browser`
- **ถ้าเปิดไม่ขึ้น:** ดู log ที่ `%LOCALAPPDATA%\Katun\katun.log`

**หน้าแรก (แบบ CapCut)**
- **เริ่มงาน:** สร้างโปรเจกต์ใหม่ (เลือกขนาด + เทมเพลต), เริ่มจากเทมเพลต หรือให้ AI ทำให้
- **ตารางโปรเจกต์:** มีภาพย่อจากเฟรมจริง ความยาว และป้าย “ส่งออกแล้ว”
- **ค้นหา กรอง เรียง:** กรองตามขนาด / ร่าง / ส่งออกแล้ว เรียงตามแก้ล่าสุด สร้างล่าสุด หรือชื่อ
- **จัดการโปรเจกต์:** เมนู ⋯ มีเปลี่ยนชื่อ ทำสำเนา เปิดโฟลเดอร์ และย้ายไปถังขยะ เลือกหลายอันพร้อมกันได้
- **ถังขยะ:** กู้คืนได้ภายใน 30 วัน

**หน้าตัดต่อ**
- **ซ้าย:**
  - บท: โครงฉากและบทพูด คลิกแล้วกระโดดไปเวลานั้น
  - ตัวละคร
  - พื้นหลัง: แบบสำเร็จรูป หรืออัปโหลดรูป
- **กลาง: พรีวิวสด:** เล่นได้ทันทีไม่ต้องเรนเดอร์ ใช้ composition เดียวกับไฟล์ที่ส่งออก ทุกครั้งที่แก้บท ระบบจะสร้างเสียงใหม่ให้เอง
- **ขวา: Inspector:** ปรับค่าของสิ่งที่เลือก
  - บทพูด: คนพูด ข้อความ ช่วงเว้น และช่องลงเสียง (ฟัง TTS / อัดไมค์พร้อม VU meter / อัปโหลด / ลากไฟล์มาวาง)
  - ฉาก ตัวละคร
  - ทั้งเรื่อง: ขนาด, fps, เสียงหลัก, ซับ, เพลงประกอบ
- **ล่าง: ไทม์ไลน์หลายแทร็ก:** ฉาก, ตัวละครแยกแทร็ก, เพลง, ซับ
  - **ลากคลิป:** ย้ายเวลา, ลากข้ามคลิปอื่นเพื่อสลับลำดับ (รวมข้ามฉาก), ลากขึ้น/ลงไปแทร็กอื่นเพื่อเปลี่ยนคนพูด
  - **ลากขอบคลิป:** ตัดหัว/ตัดท้ายเสียง ไฟล์ต้นฉบับไม่ถูกแก้ ลากขอบขวาของฉากเพื่อปรับช่วงค้างท้ายฉาก
  - **แยกคลิป (S):** แยกที่เส้นเวลา ข้อความแบ่งตามจุดที่ตัด (ภาษาไทยไม่ตัดกลางสระ/วรรณยุกต์)
  - **Ripple:** เปิด = คลิปถัดไปเลื่อนตาม, ปิด = คลิปอื่นอยู่ที่เดิม
  - **สแนป:** ดูดเข้าขอบคลิป เส้นเวลา ขอบฉาก และ marker พร้อมเส้นนำ
  - **แทร็กตัวละคร:** ปิดเสียง, ฟังเดี่ยว, ล็อก, ซ่อนตัวละครในวิดีโอ (มีผลกับไฟล์ที่ส่งออกด้วย)
  - **Marker (M):** ลากย้ายได้ ดับเบิลคลิกเปลี่ยนชื่อ คลิกขวาลบ
  - **ซูม:** Ctrl+ล้อเมาส์, ปุ่ม +/- หรือ "พอดีจอ"
- **ระบบเสียง (แผงขวาเมื่อเลือกบทพูด):**
  - **เทคเสียง:** อัด/อัปโหลดหลายครั้งเก็บเป็นเทค ฟังและเลือกเทคที่ดีที่สุดได้
  - **ปรับพื้นฐาน:** ความดัง 0–200%, fade เข้า/ออก, ความเร็ว 0.5–2× (เสียงไม่เพี้ยน), ระดับเสียง ±12 (ปุ่มลัด ตัวการ์ตูน / เด็ก / ผู้ใหญ่ / ยักษ์), กลับด้านเสียง
  - **ทำความสะอาด:** ลดเสียงรบกวน, ปรับความดังอัตโนมัติ, คอมเพรสเซอร์, ตัดเสียงต่ำ/ลม
  - **EQ** เสียงต่ำ / กลาง / แหลม
  - **เสียงพิเศษ:** วิทยุ, โทรศัพท์, โทรโข่ง, หุ่นยนต์, ใต้น้ำ + echo + ห้องก้อง (ห้องเล็ก / โถง / ถ้ำ)
  - **ฟังผล** ได้ทันที และ "ใช้กับทั้งตัวละคร" เพื่อคัดลอกเอฟเฟกต์ไปทุกบท
  - ไฟล์ต้นฉบับไม่ถูกแก้ ทุกค่าเปลี่ยนกลับได้และ Undo ได้
- **มิกซ์เสียง (แผงขวาเมื่อไม่ได้เลือกอะไร):** master, ความดังรายตัวละคร, ปิดเสียง/ฟังเดี่ยว, ความเร็วที่เพลงเบาลงรอบช่วงพูด และปรับความดังรวมตอนส่งออก (-14 LUFS สำหรับ YouTube/TikTok, -16, -23)
- **อัดตามบท (ปุ่มบนแถบบน):** บทตัวใหญ่ทีละบรรทัด นับถอยหลัง 3-2-1 มี VU meter กด Space เริ่ม/หยุด แล้วไปบรรทัดถัดไปให้เอง
- **ลากไฟล์เสียงจาก Explorer:** วางบนแทร็กตัวละคร = บทพูดใหม่ ณ เวลาที่ปล่อย, วางบนคลิป = เทคใหม่ของคลิปนั้น
- **คอมโพเนนต์ (แบบ precomp ของ After Effects, แท็บ "คอมโพเนนต์"):** ชิ้นงานที่สร้างครั้งเดียวแล้วใช้ซ้ำได้หลายที่ แก้ต้นแบบแล้วเปลี่ยนทุกจุด
  - **สร้าง:** แบบว่าง หรือจากเทมเพลต 7 แบบ (ชื่อเรื่องเด้ง, ป้ายชื่อ, ฟองคำพูด, สติกเกอร์ดาว, ถูกต้อง!, ปุ่มกดติดตาม, นับถอยหลัง 3-2-1)
  - **เลเยอร์ 6 แบบ:** ข้อความ (ฟอนต์ไทย Kanit, Prompt, Sarabun, Mitr, Chakra Petch, Itim, Mali, Noto Sans Thai), รูปทรง (สี่เหลี่ยม / วงรี / ดาว / ฟองคำพูด), รูปภาพ, ตัวละคร (ขยับปากได้), เสียง / SFX และคอมโพเนนต์ซ้อน (กันการซ้อนวนให้อัตโนมัติ)
  - **โหมดแก้ (ดับเบิลคลิก):** พรีวิวบนพื้นตาราง คลิก/ลากเลเยอร์บนจอได้, ไทม์ไลน์เลเยอร์ลากย้ายและตัดช่วงเวลาได้ แสดงคีย์เฟรมเป็น ◆, Esc เพื่อกลับเรื่องหลัก
  - **คีย์เฟรม:** ตำแหน่ง / ขนาด / หมุน / ความทึบ กดปุ่ม ◆ ที่แผงขวาเพื่อใส่คีย์ ณ เส้นเวลา (เมื่อมีคีย์แล้ว แก้ค่าที่เวลาไหนจะได้คีย์ที่เวลานั้น), easing 6 แบบ และแอนิเมชันสำเร็จรูป 10 แบบ (จางเข้า เด้งเข้า เลื่อนเข้า ตกลงมาเด้ง เต้น ส่าย จางออก ย่อหาย ฯลฯ)
  - **วางลงเรื่อง:** ปุ่ม "วาง" หรือลากจากคลังลงไทม์ไลน์ การวางยึดกับฉาก จึงเลื่อนตามเมื่อบทเปลี่ยน ลากย้าย/ปรับความยาวบนแทร็กคอมโพเนนต์ ลากตำแหน่งบนจอวิดีโอ ปรับขนาด ความทึบ ความดังเสียง และเล่นวนได้
- **คลัง SFX (แท็บ "SFX"):** 10 เสียงสังเคราะห์ด้วยโค้ด ไม่ติดลิขสิทธิ์ (ป๊อป, คลิก, ติ๊ง, กริ๊ง, วูบ, วู้ดขึ้น, เด้งดึ๋ง, วิ้ง, ตุ้บ, ปรบมือ) ฟังก่อนได้ กด + เพื่อใส่ในคอมโพเนนต์ที่แก้อยู่ หรือวางในเรื่องหลักที่เส้นเวลา
- **การแสดง (แผงขวาเมื่อเลือกบทพูด):** สีหน้า 8 แบบ (ปกติ ดีใจ หัวเราะ ตกใจ เศร้า โกรธ งง เขิน, คงอยู่จนตัวละครพูดบทถัดไป), ท่าทาง 6 แบบ (โบกมือ พยักหน้า ส่ายหัว กระโดด ชี้ สั่น) และกล้องต่อบท (ค่อย ๆ ซูมเข้า, ซูมกระแทก, กล้องสั่น) บนไทม์ไลน์คลิปแสดงอีโมจิของสีหน้า
- **สไตล์ฉาก (แผงขวาเมื่อเลือกฉาก):** ทรานสิชันเข้าฉาก 6 แบบ (จาง เลื่อน 2 ทิศ เช็ด ซูม วงกลม) ปรับความยาวได้ และไม่ทำให้เวลาของเรื่องเลื่อน, กล้องซูมหาคนพูดอัตโนมัติ, ตัวละครในฉาก: ขนาด ทิศหน้า การเข้าฉาก (เดินจากซ้าย/ขวา โผล่จากล่าง เด้ง) และ **ลากตัวละครบนจอวิดีโอเพื่อย้ายตำแหน่ง**
- **สไตล์ซับ (แผงขวาเมื่อไม่ได้เลือกอะไร):** กล่องดำ / มินิมอล / ตัวหนา TikTok / ฟองคำพูดสีตามคนพูด, ฟอนต์ไทย, สีตัวอักษรและสีไฮไลต์, **คาราโอเกะ** ไฮไลต์ทีละคำ (ตัดคำไทยอัตโนมัติ)
- **ไทม์ไลน์:** แสดง waveform จริงของเสียงที่ใส่เอฟเฟกต์แล้ว และป้าย FX บนคลิปที่มีเอฟเฟกต์
- **บันทึกและย้อนกลับ:** บันทึกอัตโนมัติ, Undo/Redo ทุกการแก้ในไทม์ไลน์
- **ส่งออก (คิวงาน):**
  - **รูปแบบ:** MP4, WebM, GIF, หรือเฉพาะเสียง MP3 / WAV
  - **ความละเอียด:** ตัวอย่าง 540p / 720p / 1080p / 4K
  - **คุณภาพ:** ร่าง / มาตรฐาน / สูง
  - **fps:** 24 / 25 / 30 / 60
  - **ตัวเลือก:** ฝังซับในภาพ และปรับความดังมาตรฐาน
  - **คิว:** กดเพิ่มได้หลายงาน ระบบเรนเดอร์ทีละงาน ยกเลิกได้ทั้งงานที่รอและงานที่กำลังทำ
  - **ไฟล์อื่น:** ดาวน์โหลดซับ .srt / .vtt และไฟล์โปรเจกต์ .katun
- **ไฟล์ .katun:** รวมโปรเจกต์ เสียงที่อัด และรูปทั้งหมดเป็นไฟล์เดียว ใช้ย้ายเครื่องหรือส่งต่อ
  - **ส่งออก:** เมนู ⋯ ที่หน้าแรก หรือในหน้าต่างส่งออก
  - **นำเข้า:** ปุ่ม "นำเข้า .katun" ที่หน้าแรก ได้เป็นโปรเจกต์ใหม่ ไม่ทับของเดิม
- **AI ช่วย (Claude):** ใส่ Claude API key ในหน้าตั้งค่าก่อน
  - **หน้าแรก "ให้ AI ทำให้":** พิมพ์หัวข้อ เลือกความยาว จำนวนตัวละคร ขนาด และภาษา ได้โปรเจกต์พร้อมบท สีหน้า และท่าทาง
  - **ปุ่ม "AI ช่วย" ในหน้าตัดต่อ:** ปรับบททั้งเรื่อง (สั้นลง ยาวขึ้น ตลกขึ้น สำหรับเด็ก ทางการ), แปลบท และแนะนำสีหน้า ท่าทาง กล้อง กด Ctrl+Z ย้อนได้ในขั้นเดียว
  - **ไม่มี key:** ใช้ผ่าน Claude Desktop / Claude Code (MCP) แทนได้
- **คีย์ลัด:**

| ปุ่ม | ทำอะไร |
|---|---|

| ← / → | ทีละเฟรม (Shift = ทีละวินาที) |
| Home / End | ต้นเรื่อง / ท้ายเรื่อง |
| S | แยกคลิปที่เส้นเวลา |
| M | เพิ่ม marker |
| Ctrl+D | ทำสำเนาบทพูด |
| Delete | ลบบทพูดที่เลือก |
| + / - | ซูมไทม์ไลน์ |
| Ctrl+Z / Ctrl+Shift+Z | ย้อน / ทำซ้ำ |

**ตั้งค่า & เชื่อมต่อ AI**
- ปุ่ม **ทดสอบ MCP** จะเริ่ม server แบบ stdio และตรวจการตอบสนองจริง พร้อมจำนวนเครื่องมือและ prompts โดยไม่ต้องมี Claude API key
- สถานะ **ตั้งค่าแล้ว** ของ Claude Desktop / Claude Code หมายถึงพบการตั้งค่าในแอปนั้น ต้องเปิดแอปเพื่อตรวจการเชื่อมต่อจริง สถานะนี้แยกจากตัว Katun MCP server
- ใส่ Azure key สำหรับเสียงไทย และ Claude API key สำหรับปุ่ม AI ช่วย (เก็บใน `.env` บนเครื่องนี้เท่านั้น)
- ตรวจความพร้อมของเครื่อง และติดตั้ง Rhubarb
- ปุ่มเชื่อม Claude Desktop / Claude Code

## เสียงพูด

| แบบ | ใช้เมื่อ |
|---|---|
| Azure Neural TTS | เสียงไทยคุณภาพสูง (เปรมวดี, อัจฉรา, นิวัฒน์) ใส่ key ในหน้าตั้งค่า |
| เสียงในเครื่อง Windows | ทดสอบได้ทันทีโดยไม่ต้องมี key (ภาษาอังกฤษ) |
| อัดเอง / อัปโหลด | ใช้เสียงคนจริงหรือเสียงจากโปรแกรมอื่น |

เสียง TTS ถูกเก็บไว้ (cache) แก้บรรทัดเดียวก็สร้างใหม่แค่บรรทัดนั้น

## เชื่อมกับ AI ผ่าน MCP

กดปุ่ม **เชื่อมต่อ** ในหน้า *ตั้งค่า & เชื่อมต่อ AI* หรือใช้คำสั่ง:

```bash
katun connect claude-desktop
```

```bash
katun connect claude-code
```

หลังเชื่อม Claude Desktop ให้ปิดแอปให้สนิท (รวมไอคอนที่มุมจอ) แล้วเปิดใหม่ แอป AI อื่นที่รองรับ MCP แบบ stdio ให้ตั้งคำสั่งเป็น `node <โฟลเดอร์ katun>\bin\katun.js mcp`

ตัวอย่างคำสั่งที่พิมพ์ใน Claude ได้: *"ทำคลิปแนวตั้ง 20 วินาที น้องนกสอนนับเลข 1–3 ใช้เสียงเปรมวดี ใส่ซับด้านบน แล้วเรนเดอร์ตัวอย่างให้ดู"* หรือเลือก prompt สำเร็จรูป **make_video**

**เครื่องมือ MCP (44 ตัว)**

| กลุ่ม | เครื่องมือ |
|---|---|
| โปรเจกต์ | `list_projects`, `create_project`, `get_project`, `save_project` |
| บทและฉาก | `add_scene`, `remove_scene`, `add_line`, `update_line`, `remove_line`, `set_background` |
| ตัวละครและเสียง | `set_character`, `list_voices`, `attach_voice`, `set_audio_fx`, `set_mix`, `set_track`, `set_scene_style` |
| ซับและเพลง | `set_subtitles`, `get_subtitles`, `set_music` |
| ผลิตวิดีโอ | `prepare_project`, `preview_frame` (ส่งภาพกลับให้ AI ดู), `render_video`, `export_video` (ทุกรูปแบบ/ความละเอียด เข้าคิว), `get_render_status`, `cancel_export` |
| ไฟล์โปรเจกต์ | `export_bundle`, `import_bundle` (.katun) |
| คอมโพเนนต์ | `list_components`, `create_component`, `get_component`, `save_component`, `delete_component`, `add_layer`, `update_layer`, `remove_layer`, `set_keyframe`, `apply_animation`, `add_sfx`, `place_component` |
| ระบบ | `check_setup` |
| หน้าต่างโปรแกรม | `get_app_state`, `open_in_app`, `control_playback` |

**ดู AI ทำงานในหน้าต่าง Katun ที่เปิดอยู่**

เปิดหรือรีสตาร์ต Katun รุ่นล่าสุด แล้วตรวจว่ามุมล่างขวามีข้อความ “MCP พร้อมรับคำสั่ง · ซิงก์อัตโนมัติ” จากนั้น AI ใช้ `get_app_state` ดูหน้าต่างที่เปิดจริง และส่ง `open_in_app` พร้อมชื่อโปรเจกต์และ `session_id` ไปยังหน้าต่างนั้น ใช้ `control_playback` เพื่อเล่น หยุด หรือเลื่อนไปเวลาที่ต้องการ ทั้งสองคำสั่งคืน `command_id` ให้ตรวจผลด้วย `get_app_state` ก่อนรายงานว่าสำเร็จ หากมีหลายหน้าต่างต้องระบุ `session_id` หรือมีหน้าต่างที่โฟกัสเพียงอันเดียว

บท ฉาก ตัวละคร และรายการโปรเจกต์ที่ MCP แก้จะอัปเดตอัตโนมัติประมาณทุก 2 วินาที หน้าจอจะไม่แทนที่งานที่ผู้ใช้ยังไม่บันทึก และจะปฏิเสธการบันทึกหากข้อมูลบนดิสก์ถูกแก้จากอีกทางก่อน เพื่อป้องกันการเขียนทับกัน การเปลี่ยน source ของโปรแกรมครั้งแรกต้องเปิด Katun ใหม่หนึ่งครั้ง

Prompt: `make_video` (หัวข้อ, ขนาด, ความยาว) จะพา AI ทำครบทุกขั้นตอน

ทดสอบทั้งหมด: `npm test` (ไทม์ไลน์ `test:timeline`, ระบบเสียง `test:audio`, คอมโพเนนต์ `test:components`, การแสดง `test:acting`, ส่งออก/.katun `test:export`, MCP `test:mcp`)

ตรวจพร้อมใช้งานด้วยคำสั่งเดียว: `npm run check` (ตรวจ TypeScript รวมสคริปต์ทดสอบ → build → ทดสอบครบ รวม `test:live` สำหรับคำสั่งหน้าต่าง การซิงก์ และการบันทึกชนกัน)

ชุดทดสอบสร้างโปรเจกต์และไฟล์เสียงตัวอย่างของตัวเองใน `projects/test-<ชุด>-<ชื่อสุ่ม>/` และล้างเมื่อจบ จึงไม่ต้องมี `demo-offline` และไม่เขียนทับโปรเจกต์ผู้ใช้ การทดสอบ pipeline และส่งออกจะไม่ถูกข้ามเพราะไม่มีข้อมูลตัวอย่าง ส่วน MCP ทดสอบ Windows TTS, แนบไฟล์เสียง และเพลงประกอบจริงด้วย ต้องใช้ Windows พร้อมเสียง Zira / David และ Chrome Headless ของ Remotion

## project.json

แต่ละเรื่องอยู่ใน `projects/<ชื่อ>/project.json` จะแก้ในโปรแกรม ให้ AI แก้ หรือแก้ไฟล์เองก็ได้

```jsonc
{
  "title": "น้องนกกับพี่หมี",
  "format": "16:9",
  "fps": 30,
  "voice": { "provider": "azure", "voice": "th-TH-PremwadeeNeural" },
  "characters": {
    "nok": { "name": "น้องนก", "color": "#f4a261" },
    "mee": { "name": "พี่หมี", "color": "#8ecae6",
             "voice": { "provider": "azure", "voice": "th-TH-NiwatNeural", "rate": "-5%" } }
  },
  "subtitles": { "enabled": true, "position": "bottom", "size": "medium", "showName": true },
  "music": { "file": "assets/song.mp3", "volume": 0.25, "duckTo": 0.08 },
  "scenes": [
    {
      "id": "park",
      "background": "linear-gradient(#bde0fe, #e0fbfc)",
      "lines": [
        { "character": "nok", "text": "สวัสดีค่ะ" },
        { "character": "mee", "text": "สวัสดีครับ", "audio": "voices/mee-01.wav", "pauseAfter": 0.6 }
      ]
    }
  ]
}
```

ผลลัพธ์อยู่ใน `projects/<ชื่อ>/out/`:
- **วิดีโอหลัก:** `<ชื่อ>.mp4`
- **ตัวอย่าง:** `<ชื่อ>-preview.mp4`
- **ไฟล์ส่งออกแบบอื่น:** เช่น `<ชื่อ>-4k-60fps.webm` หรือ `<ชื่อ>-audio.mp3`
- **ซับ:** `<ชื่อ>.srt` และ `<ชื่อ>.vtt`

## ยังไม่มี (แผนถัดไป)
