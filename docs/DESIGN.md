# Katun Studio v2: สเปกโปรแกรมตัดต่อระดับโปรดักชัน

เป้าหมาย: เปลี่ยนจาก "ฟอร์มกรอกบทแล้ว AI เจน" เป็นโปรแกรมตัดต่อแบบ CapCut ที่คนปรับแต่งได้ทุกอย่าง โดย AI (ผ่าน MCP) เป็นผู้ช่วยที่ใช้ข้อมูลชุดเดียวกัน คนเปิดงานที่ AI ทำมาแก้ต่อได้ทันที และ AI ก็แก้งานที่คนทำได้

หลักการ:
- **WYSIWYG:** พรีวิวในโปรแกรมใช้ composition เดียวกับตอนเรนเดอร์ เห็นอะไรได้อย่างนั้น
- **แก้ได้เสมอ ย้อนได้เสมอ:** Undo/Redo ทุกการกระทำ บันทึกอัตโนมัติ และไม่ทำลายไฟล์ต้นฉบับ (เอฟเฟกต์เสียงเก็บเป็นค่า ไม่ทับไฟล์)
- **ลากวางได้ทุกที่:** ลากไฟล์จาก Windows Explorer มาวางในโปรแกรมได้เลย

---

## 1. หน้าจอ

### 1.1 หน้าแรก (Home) แบบ CapCut
- **ปุ่มใหญ่ด้านบน:** โปรเจกต์ใหม่ (เลือกขนาด 16:9 / 9:16 / 1:1 / 4:5), ให้ AI เขียนบท, เริ่มจากเทมเพลต, นำเข้าไฟล์ `.katun`
- **ตารางโปรเจกต์:** มีภาพย่อจากเฟรมจริง ความยาว ขนาด เวลาแก้ล่าสุด และป้ายสถานะ (ร่าง / ส่งออกแล้ว)
- **ค้นหา กรอง เรียง:** ค้นหาชื่อ กรองตามขนาดหรือสถานะ เรียงตามแก้ล่าสุด ชื่อ หรือวันที่สร้าง
- **เมนูของแต่ละโปรเจกต์:** เปิด, ทำสำเนา, เปลี่ยนชื่อ, ส่งออก `.katun`, เปิดโฟลเดอร์, ลบ (ย้ายไปถังขยะ กู้คืนได้ 30 วัน)
- **เลือกหลายอัน:** ลบหรือส่งออกพร้อมกันได้
- **ถังขยะ:** ดูรายการที่ลบไว้และกู้คืนได้

### 1.2 หน้าตัดต่อ (Editor)
แบ่งเป็น 4 โซน:

| โซน | เนื้อหา |
|---|---|
| ซ้าย: คลังสื่อ | แท็บ ตัวละคร / เสียงของฉัน / SFX / เพลง / ฉากและพื้นหลัง / ข้อความและสติกเกอร์ / เอฟเฟกต์และทรานสิชัน ลากลงไทม์ไลน์หรือลงจอพรีวิวได้ |
| กลาง: พรีวิว | เล่นสดทันที (ไม่ต้องเรนเดอร์) เลื่อนเฟรมได้ คลิกตัวละครบนจอเพื่อเลือก ลากเพื่อย้ายตำแหน่ง ซูมได้ (Fit / 50% / 100%) และปิด/เปิดซับในพรีวิวได้ |
| ขวา: Inspector | แสดงค่าของสิ่งที่เลือกอยู่ (คลิปเสียง บทพูด ตัวละคร ฉาก SFX ข้อความ) แก้ได้ทันทีและเห็นผลในพรีวิว |
| ล่าง: ไทม์ไลน์ | หลายแทร็ก ซูมได้ สแนปเข้าหากัน แสดง waveform ทุกคลิปเสียง |

แถบบน: ชื่อเรื่อง, สถานะการบันทึก, Undo/Redo, ปุ่ม AI ช่วย, ปุ่มส่งออก

### 1.3 หน้าต่างส่งออก
- **วิดีโอ:**
  - ความละเอียด 720p / 1080p / 4K
  - fps 24 / 30 / 60
  - คุณภาพ ร่าง / มาตรฐาน / สูง
  - รูปแบบ MP4 (H.264) / WebM / GIF
- **เฉพาะเสียง:** WAV / MP3
- **ซับไตเติล:** SRT / VTT แยกไฟล์ หรือฝังในวิดีโอ
- **ไฟล์โปรเจกต์ `.katun`:** zip ที่รวมสื่อทั้งหมด ย้ายเครื่องหรือส่งให้คนอื่นแก้ต่อได้
- **ระหว่างส่งออก:** แถบความคืบหน้า + เวลาที่เหลือ และส่งออกต่อคิวได้หลายงาน

### 1.4 ตั้งค่า
ของเดิมทั้งหมด (Azure TTS, ตรวจเครื่อง, เชื่อม MCP) และเพิ่ม:
- ตำแหน่งเก็บโปรเจกต์
- ภาษา UI (ไทย / อังกฤษ)
- คีย์ลัด
- ค่าเริ่มต้นของโปรเจกต์ใหม่

## 2. ไทม์ไลน์

### แทร็ก
| แทร็ก | คลิป |
|---|---|
| ฉาก | ช่วงของแต่ละฉาก ปรับความยาวได้ ใส่ทรานสิชันได้ระหว่างฉาก |
| ตัวละคร (1 แทร็กต่อตัว) | บทพูด: ข้อความ + เสียง (TTS / อัด / อัปโหลด) |
| SFX (เพิ่มได้หลายแทร็ก) | เสียงประกอบ วางเวลาอิสระหรือผูกกับบทพูด |
| เพลง (เพิ่มได้หลายแทร็ก) | เพลงประกอบ |
| ข้อความ / สติกเกอร์ | ชื่อเรื่อง คำบรรยาย สติกเกอร์ |
| ซับ | สร้างจากบทพูดอัตโนมัติ แก้ข้อความหรือเวลาแยกได้ |
| กล้อง | keyframe ซูม แพน และสั่น |

### การทำงานกับคลิป
- ลากย้าย, ตัดหัวท้าย (trim), แยกคลิปที่เส้นเวลา (split: S), ทำสำเนา, ลบ
- เลือกหลายคลิป (Shift / ลากคลุม) แล้วย้ายพร้อมกัน
- สแนปเข้าขอบคลิป เส้นเวลา และ marker
- **Ripple:** เลื่อนบทพูดถัดไปตามเมื่อความยาวเสียงเปลี่ยน (เปิด/ปิดได้)
- **แทร็ก:** ล็อก, ปิดเสียง (M), ฟังเดี่ยว (S), ซ่อน
- **ไทม์ไลน์:** ซูม (Ctrl + ล้อเมาส์) และ marker สำหรับจดจุดสำคัญ

## 3. ระบบเสียง

### 3.1 นำเสียงเข้า
- **ลากวาง:** ลากไฟล์ wav / mp3 / m4a / ogg / webm จาก Explorer มาวางที่บทพูด แทร็ก หรือคลังสื่อ
- **อัดเสียง:**
  - นับถอยหลัง 3-2-1 และเห็นระดับเสียง (VU meter) ระหว่างอัด
  - อัดซ้ำได้หลายเทค (take) แล้วเลือกเทคที่ดีที่สุด
  - **โหมดอัดตามบท:** โชว์บทพูดทีละบรรทัดให้อ่าน อัดต่อเนื่องทั้งเรื่องได้
- **TTS:** เลือกเสียง ความเร็ว ระดับเสียง และสไตล์อารมณ์ (Azure รองรับ cheerful / sad / angry ฯลฯ) ฟังก่อนกดใช้ได้
- **คลังเสียงของฉัน:** เสียงทุกไฟล์ที่เคยอัดหรืออัปโหลด ใช้ซ้ำข้ามบรรทัดได้

### 3.2 ปรับคลิปเสียง (Inspector)
- ความดัง 0–200% และ envelope (จุดควบคุมความดังบน waveform)
- Fade in / fade out
- ตัดหัวท้าย และตัดช่วงเงียบอัตโนมัติ
- ความเร็ว 0.5×–2× (เสียงไม่เพี้ยน) และระดับเสียง ±12 semitone
- กลับด้านเสียง

### 3.3 เอฟเฟกต์เสียง (ซ้อนกันได้เป็น chain)
| เอฟเฟกต์ | การใช้ |
|---|---|
| ลดเสียงรบกวน (AI) | RNNoise ลบเสียงพัดลม/แอร์จากเสียงที่อัด |
| ปรับความดังมาตรฐาน | ปรับเป็น -14 LUFS (YouTube/TikTok) อัตโนมัติ |
| คอมเพรสเซอร์ | เสียงพูดสม่ำเสมอ ฟังชัด |
| EQ | เบส / กลาง / แหลม, ตัดเสียงต่ำ |
| ห้องก้อง (Reverb) | ห้องเล็ก / ห้องโถง / ถ้ำ |
| เสียงสะท้อน (Echo) | ดีเลย์ปรับได้ |
| วิทยุ / โทรศัพท์ | band-pass + ความเพี้ยน |
| หุ่นยนต์ | ring modulator |
| ตัวการ์ตูน (เสียงสูง) / ยักษ์ (เสียงต่ำ) | preset ปรับระดับเสียง |
| พูดในน้ำ / กระซิบ | preset รวม |

ทุกเอฟเฟกต์เก็บเป็นค่าในโปรเจกต์ (non-destructive) ตอนเรนเดอร์ระบบจะ "bake" เป็นไฟล์ใหม่ใน build/ ไฟล์ต้นฉบับไม่ถูกแตะ

### 3.4 มิกซ์
- ความดังรายแทร็กและความดังรวม (master) พร้อมมิเตอร์
- **Auto-ducking:** เพลงและ SFX เบาลงตอนมีคนพูด ปรับได้ว่าเบาลงเท่าไรและเร็วแค่ไหน

### 3.5 คลัง SFX
- **ชุดในตัว:** สังเคราะห์ด้วยโค้ด จึงไม่มีปัญหาลิขสิทธิ์ เช่น ป๊อป วูบ ติ๊ง บึ้ม เด้ง ปรบมือ ฝีเท้า กริ่ง เสียงหัวเราะสั้น และ UI click
- **ใส่เพิ่มเอง:** นำเข้าไฟล์ของผู้ใช้และจัดเป็นหมวด
- **ค้นหาง่าย:** ติดดาว (favorite) และค้นหาได้
- **ใช้งาน:** ลากจากคลังลงไทม์ไลน์ หรือคลิกขวาที่บทพูดแล้วเลือก "ใส่ SFX ตรงนี้"

## 4. ภาพและเอฟเฟกต์

### ตัวละคร
- **ตัวละครสำเร็จรูป:** หลายแบบ (คน สัตว์ มาสคอต) ปรับสี ขนาด และรูปร่างหัว/ตัวได้
- **อารมณ์ต่อบทพูด:** ปกติ ยิ้ม หัวเราะ ตกใจ เศร้า โกรธ งง เขิน (เปลี่ยนตา คิ้ว ปาก และสีแก้ม)
- **ท่าทาง:** โบกมือ พยักหน้า ส่ายหัว กระโดด ชี้
- **ตำแหน่งและทิศ:** ลากตัวละครบนจอได้ หันซ้าย/ขวา
- **การเคลื่อนไหว:** เดินเข้า/ออกฉาก (ซ้าย ขวา ล่าง), ค่อย ๆ ปรากฏ, เด้งเข้า
- **ตัวละครจากรูป:** นำเข้า PNG ที่แยกชิ้นหัว ตัว และปากหลายรูปได้

### ฉาก
- **พื้นหลัง:** สี, gradient, รูป, วิดีโอวนซ้ำ
- **ฉากสำเร็จรูป:** ห้องเรียน สวน ห้องนอน ทะเล ฯลฯ
- **ทรานสิชันระหว่างฉาก:** fade, slide, wipe, zoom, iris (`@remotion/transitions`)

### กล้อง
ซูมเข้าคนพูดอัตโนมัติ (เปิด/ปิดได้), แพน, สั่น (ตอนตกใจ / บึ้ม) และ keyframe เอง

### ข้อความและสติกเกอร์
- **ข้อความ:** ชื่อเรื่อง คำบรรยาย ลูกศร อีโมจิ และฟองคำพูด
- **ฟอนต์:** ฟอนต์ไทยจาก Google Fonts (Sarabun, Kanit, Prompt, Mitr ฯลฯ)
- **แอนิเมชันเข้า/ออก:** พิมพ์ทีละตัว เด้ง จาง

### ซับไตเติล
- **สไตล์สำเร็จรูป:** มินิมอล, กล่องดำ, ขอบหนาแบบ TikTok, การ์ตูน
- **ปรับละเอียดได้:** ฟอนต์ ขนาด สี ขอบ เงา ตำแหน่ง (ลากบนจอ) และการแสดงชื่อคนพูด
- **ไฮไลต์คำที่กำลังพูด:** แบบคาราโอเกะ ใช้เวลาจาก TTS หรือ Whisper
- **ภาษาไทย:** ตัดบรรทัดตามคำ ไม่ตัดกลางคำ

## 5. AI ช่วย (ไม่บังคับ)
- **ปุ่ม "AI ช่วย" ในโปรแกรม:**
  - เขียนบทจากหัวข้อ
  - ปรับบทให้สั้นหรือยาวลง
  - แนะนำอารมณ์และ SFX ให้แต่ละบรรทัด
  - แปลบทเป็นภาษาอื่น
- **MCP:** อัปเดตเครื่องมือให้ครอบคลุมทุกความสามารถใหม่ (คลิป เอฟเฟกต์เสียง SFX อารมณ์ กล้อง ทรานสิชัน ข้อความ ส่งออก) งานที่ AI ทำจะเปิดในโปรแกรมแล้วแก้ต่อได้ทันที
- **ทุกอย่างที่ AI ทำ Undo ได้** และแสดงในประวัติว่า "แก้โดย AI"

## 6. ระบบพื้นฐาน
- **ประวัติการแก้:** Undo/Redo ไม่จำกัดในเซสชัน และประวัติเวอร์ชันย้อนดูได้
- **บันทึก:** บันทึกอัตโนมัติ และกู้คืนได้ถ้าโปรแกรมปิดกะทันหัน
- **คีย์ลัดแบบมาตรฐาน:**
  - Space เล่น/หยุด, S แยกคลิป, Delete ลบ
  - Ctrl+Z / Ctrl+Shift+Z ย้อน/ทำซ้ำ, Ctrl+D ทำสำเนา
  - ← → ทีละเฟรม, J K L ควบคุมการเล่น
- **ไฟล์โปรเจกต์:** มีเลขเวอร์ชัน (schema v2) และย้ายจากโปรเจกต์ v1 ให้อัตโนมัติ
- **ภาพย่อ:** สร้างอัตโนมัติจากเฟรมจริงของเรื่อง

## 7. เทคโนโลยี

| ส่วน | เลือกใช้ | เหตุผล |
|---|---|---|
| หน้าจอ | React 19 + TypeScript + Vite 8 | มาตรฐานปัจจุบัน และใช้ composition เดียวกับ Remotion ได้ |
| สไตล์ | Tailwind CSS 4 + ไอคอน lucide-react | ทำ UI ระดับโปรดักชันได้เร็วและสม่ำเสมอ |
| สถานะ + Undo | zustand 5 + history stack (patches) | เบา เร็ว Undo ได้ทุกการกระทำ |
| พรีวิวสด | `@remotion/player` 4.0.539 | เล่น composition จริงในหน้าโปรแกรม ไม่ต้องเรนเดอร์ |
| ทรานสิชัน | `@remotion/transitions` | ทรานสิชันมาตรฐานของ Remotion |
| Waveform | wavesurfer.js 8 (+ regions plugin) | วาด waveform, ตัดหัวท้าย, envelope |
| ลากวาง | dnd-kit + HTML5 drag-drop สำหรับไฟล์ | ลากในโปรแกรมและลากไฟล์จาก Explorer |
| เอฟเฟกต์เสียง | Web Audio API (OfflineAudioContext) | ฟังสดได้และ bake เป็น WAV ด้วยกราฟเดียวกัน |
| ลดเสียงรบกวน | `@sapphi-red/web-noise-suppressor` (RNNoise, MIT) | AI denoise ในเบราว์เซอร์ ไม่ต้องลงโปรแกรมเพิ่ม |
| ปรับความดังมาตรฐาน | ffmpeg `loudnorm` (มากับ Remotion) | ได้มาตรฐาน EBU R128 |
| ฟอนต์ | `@remotion/google-fonts` | ฟอนต์ไทยโหลดถูกต้องทั้งพรีวิวและตอนเรนเดอร์ |
| เรนเดอร์ | Remotion 4 (เดิม) | ใช้งานได้แล้วและทดสอบผ่าน |
| Backend | Node server เดิม + API ใหม่สำหรับคลิป สื่อ ถังขยะ ภาพย่อ และคิวส่งออก | ต่อยอดจากของเดิม |

หมายเหตุ: ffmpeg ที่มากับ Remotion เป็นรุ่นตัดฟิลเตอร์ (มีแค่ loudnorm / atempo / asetrate) เอฟเฟกต์เสียงจึงทำด้วย Web Audio ทั้งหมด
